# Самоаудит Ulash 1.0.0 перед TestFlight

После переработки код проверили ещё раз: сам автор изменений и два независимых ревьюера без доступа к его выводам (нативная часть; Dart-дифф). Ниже — что найдено, что сделано и что сознательно оставлено.

## Найдено и исправлено

| # | Проблема | Исправление |
|---|---|---|
| 1 | Сброс ключей из настроек показывал экран ошибки запуска | перезапуск «на месте», без смены экрана |
| 2 | Сброс ключей стирал тему, язык, квоту и повторял онбординг | сохраняются все настройки, сбрасываются только ключи и пары |
| 3 | Новое имя устройства не доходило до уже подключённых | имя передаётся в аутентифицированном ответе по закреплённому ключу |
| 4 | Запись в Keychain каждые 12 с на каждое устройство | запись только при изменении адреса |
| 5 | После перезапуска хоста менялся порт, сохранённые адреса устаревали | повторно используется последний порт |
| 6 | Уход в другое приложение из системного окна или сканера QR не обрабатывался | состояние применяется после закрытия окна; сканер не подавляет сворачивание |
| 7 | Перезапуск мог ждать чужую передачу, запущенную автопродолжением | флаг перезапуска блокирует автопродолжение |
| 8 | Нажатие «Продолжить» могло молча проиграть очереди автопродолжения | явное действие имеет приоритет, иначе понятное сообщение |
| 9 | Автоочистка истории удаляла подготовленные копии | удаляются только записи; копии видны в «Неиспользуемых копиях» |
| 10 | Новый журнал после восстановления удалял все подготовленные копии | новый журнал никогда не удаляет существующие копии |
| 11 | Перезапуск хоста мог необратимо испортить частично принятый файл | обрыв по перезапуску — возобновляемый |
| 12 | Повтор при ограничении частоты запросов вводил в заблуждение | `RATE_LIMITED` не повторяется, понятный текст |
| 13 | Имена от подключённых устройств не очищались от невидимых символов | применяется тот же фильтр |
| 14 | «Восстановить журнал» предлагался и для журнала более новой версии | только для повреждённого журнала |
| 15 | iOS завершал приложение при «Сохранить изображение» из «Поделиться» | добавлен `NSPhotoLibraryAddUsageDescription` |
| 16 | Обработчик истечения фоновой задачи захватывал изменяемую переменную | безопасный вариант без захвата |
| 17 | Ошибка получения номера сборки скрывалась, возможен дубликат загрузки | ошибка видна; номер не ниже UTC-метки времени |
| 18 | Журнал диагностики писал в папку после закрытия | сброс и отвязка при закрытии |
| 19 | Скорость передачи не показывалась | сглаженная скорость и оставшееся время |

## Сознательные решения

- **Автопродолжение после фона и обрыва.** Изначальные правила проекта запрещали его. Для релиза выбрано поведение, которого ждут пользователи: продолжение только в открытом приложении, после свежей проверки ключа, не более 3 раз на передачу; ручная пауза никогда не снимается. Правило обновлено в `AGENTS.md`.
- **Подстановка приглашения из буфера обмена отклонена:** на iOS 16+ она вызывает системный запрос «Разрешить вставку» при каждом открытии.
- **Крэш-репортинг без сторонних SDK:** нативные сбои видны в App Store Connect / Play Console; ошибки Dart пишутся в локальный журнал, который пользователь отправляет сам. Так карточка остаётся «Data Not Collected».
- **iPad включён:** раскладка адаптивная; потребуются скриншоты iPad 13".

## Известные ограничения (план 1.1+)

1. Передача только при открытом приложении (+20 с фона). Следующий шаг — iOS Share Extension («Поделиться → Ulash» из «Фото») и фоновая загрузка через `URLSession`; Android — user-initiated data transfer job.
2. Сохранённые описания передач остаются на языке, на котором были записаны (нужен перевод при показе по коду).
3. Только IPv4 в одной сети; deep link по ссылке-приглашению (`xferapp://`) не зарегистрирован.
4. Узбекские тексты переведены без носителя языка.
5. Нужна физическая матрица iPhone ↔ Android ↔ Windows (1 МБ / 1 ГБ / 5 ГБ), проверка запроса «Локальная сеть» и фонового времени на реальном iPhone.
6. Контроллер (≈2400 строк) и UI (≈3000 строк) по-прежнему крупные; разделение на сервисы и виджеты — технический долг.
