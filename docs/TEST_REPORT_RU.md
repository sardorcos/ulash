## 3. Дефекты, найденные и исправленные в этой итерации

- Потенциальное зависание флагов busy/exporting при исключении до блока `finally`.
- Гонка: системный picker возвращался во время сохранения новой квоты и мог начать подготовку до завершения операции настроек.
- Поздний результат picker мог быть обработан после начала shutdown.
- Причина `DISK_FULL` заменялась общим `TRANSFER_INTERRUPTED` при открытии прежней paused-передачи.
- Для автоматически приостановленного приёма без ручного Sink-флага не отображалась кнопка возобновления.
- iOS системный document picker требовал корректного момента установки delegate интерактивного закрытия.
- Windows modal-dialog message loop требовал сохранения времени жизни StorageChannel при уничтожении окна.
- Имя из wire manifest могло быть непригодным для системного Save dialog; теперь используется безопасное локальное имя готового файла.
- В Android manifest попадали ненужные широкие разрешения чтения медиа из зависимости просмотрщика; они исключены для текущего app-private/SAF сценария.

## 4. Интерфейс

`docs/previews/` содержит рендер настоящих Flutter widgets. В этой итерации harness использует реальный `TransferAppController`, временные SQLite, TLS Host и бюджет. Придуманных устройств, переданных файлов, истории и прогресса нет. В Linux нативное значение свободного места недоступно, поэтому именно это видно на снимках.

Временный Host закрыт после захвата изображений, секреты уничтожены. Снимок мобильного размера не является фотографией запуска на iPhone или Android. Desktop/mobile snapshots визуально просмотрены; проверка 360 px и180% текста включена в UI-тесты.

## 6. Границы доказанного

Не выполнены:

- шесть межплатформенных направлений и ещё три направления внутри одной ОС;
- маршрутизатор с выключенным WAN, реальные Wi-Fi/hotspot/firewall/VPN сценарии;
- системные разрешения, камера, Keychain/Keystore/DPAPI и документные провайдеры на целевых физических устройствах;
- внешний экспорт при сбое провайдера, заполненном внешнем диске, недоступном облаке и закрытии приложения на каждой ОС;
- файлы 5/10 ГиБ, 1 000 файлов, 50 ГиБ пакет, аппаратные RAM/p95/скоростные показатели;
- native background, Share Extension, Android foreground service, Windows tray;
- retention 7/30 дней, ограничение истории и очистка незавершённых входящих/orphan данных;
- аппаратное отключение питания и независимый security audit.

Квота 20 ГиБ и запас 128 МиБ — проектные настройки. Проверка их математического учёта не означает проверки физических размеров на телефонах. Gate A из ТЗ остаётся открытым; следующая приёмка описана в `DEVICE_TEST_MATRIX.md`.
